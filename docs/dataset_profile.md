\# CareFlow Dataset Profile



\## Dataset

Sepsis Cases – Event Log



\## Source

Felix Mannhardt (2016), 4TU.ResearchData



Official source: https://data.4tu.nl/articles/\_/12707639/1



\## Purpose

Evaluate clinical pathways and process performance using PM4Py.



\## Initial Profile

\- Event records: 15,214

\- Case IDs: approximately 1,049

\- Unique activities: 16

\- Missing case IDs: 24

\- Missing activity names: 0

\- Missing timestamps: 0

\- Duplicate full rows: 1



\## Limitations

The dataset documentation states that timestamps were randomised. Calendar-based trend analysis must therefore be treated cautiously.
